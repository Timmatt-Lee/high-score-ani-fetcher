## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please **DO NOT** create a public issue. Instead, please report it securely through GitHub's Private Vulnerability Reporting system:

1. Navigate to the main page of the repository.
2. Under the repository name, click **Security**.
3. In the left sidebar, under **Reporting**, click **Advisories**.
4. Click **Report a vulnerability** to privately submit your findings.

We take security seriously and will review your report as soon as possible. Thank you for helping keep this project safe!
